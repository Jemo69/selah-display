# Set up Sermon Assist

You do not need to know about computer files to use this. Selah does the choosing and the installing for you.

## One-time setup

1. Open **User Preferences** from the menu.
2. Choose **Experimental**, then find **Sermon Assist**.
3. Press **Set up Sermon Assist** once.
4. Wait while Selah says what it is doing. This can take a few minutes on a slow internet connection.
5. When it says **Sermon Assist is set up**, it starts listening automatically. If your computer asks for microphone access, choose **Allow**.

You do **not** need to:

- download or unzip a file yourself;
- decide which program or model file to use;
- install a graphics driver or change computer settings;
- copy anything into a folder.

Nothing listens to the microphone until you press **Start**. Audio stays on this computer.

## What Selah downloads

Selah checks the computer first and picks the pieces that fit it.

- On a computer with a suitable NVIDIA graphics card, it installs the matching engine first, then gets the larger, more accurate voice model. The engine download can be up to about 650 MB and the model about 1.5 GB.
- On any other computer, it gets a small voice model of about 31 MB and an engine of about 9 MB. It will still work, but large voice models are too slow for live use there.

If Selah already finds an older engine on a graphics-card computer, it replaces it inside the app. You do not remove files or copy anything yourself.

Selah checks every download before using it. If a download is damaged, nothing bad is installed and Selah tells you to try again.

## If setup does not finish

1. Check that the computer is online.
2. Press **Try setup again**.
3. If it still fails, open **Details for tech support** and send that text to whoever looks after the computer. You do not need to act on it yourself.

## After setup

The **Start** button turns listening on. The benchmark card further down the settings page measures this computer and tells you if a voice model cannot keep up. A suggestion only appears after a real measurement. Selah never guesses that a graphics card made things faster.
